# Cash Book Management System Backend

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Make sure MongoDB is running on `mongodb://localhost:27017`

3. Start development server:
   ```bash
   npm run dev
   ```

4. The server will seed the database with the default admin user:
   - Email: `admin@cashbook.com`
   - Password: `Admin@1234`
